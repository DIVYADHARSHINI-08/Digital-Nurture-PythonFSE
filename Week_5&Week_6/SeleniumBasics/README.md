## Overview

This week focused on the fundamentals of Software Testing and Selenium Automation. The hands-on exercises covered software testing concepts, automation strategies, Selenium WebDriver, Pytest integration, synchronization techniques, and the Page Object Model (POM) design pattern.

The practical exercises helped build a strong foundation in test automation by implementing industry-standard practices for writing reliable, reusable, and maintainable Selenium test scripts.
