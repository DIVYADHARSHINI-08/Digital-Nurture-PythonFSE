# WEEK_6 – Agile, Git & Project Collaboration

## Overview

This module introduces Agile software development practices and Git-based version control workflows commonly used in modern software development teams. It covers Scrum, Kanban, GitHub collaboration, code reviews, DevOps culture, and project tracking tools.

## Learning Objectives

After completing this module, I was able to:

* Understand Agile principles and values.
* Differentiate Agile and Waterfall development models.
* Explain Scrum roles, ceremonies, and artifacts.
* Apply Scrum concepts during sprint planning and execution.
* Understand Kanban workflow and Work-In-Progress (WIP) limits.
* Use Git and GitHub for source code management.
* Create and manage feature branches.
* Commit code using meaningful commit messages.
* Create Pull Requests (PRs) and resolve merge conflicts.
* Participate in code reviews using best practices.
* Understand DevOps collaboration and shift-left testing.
* Manage project work using GitHub Projects, Jira, and Azure Boards.
* Break features into user stories with acceptance criteria.
* Estimate work using story points.
* Track project progress using Agile boards.
